## What This Proves

- The tested request/response schemas match across Full and Lite.
- Completion capture persists through a durable outbox and has failure/replay tests.
- Server-bound identity enforcement, lifecycle guards, MCP firewall sentinels, and privileged-default-token checks are exercised by tests.
- Runtime and MCP profiles have deterministic, tested capability boundaries.
- Continuity now measures active progress instead of relying only on event count or handoff age.
- Current third-party Python and Node dependency audits report no known vulnerabilities after applying available fixes.

## What This Does Not Prove

- It does not prove that TCE clones a human. TCE is a calibrated model of observed behavior in recurring task contexts.
- It does not yet prove that shared memory reduces real resume time. That requires the four-week controlled pilot in `docs/runbooks/continuity-pilot.md`.
- The 28% coverage gate is a regression floor, not comprehensive coverage.
- `protocol_only` governance is cooperative permit/claim/report validation. It is not OS or host command interception unless an external interceptor is deployed and attested.
- Full/Lite OpenAPI parity proves contract parity, not identical storage, search backend, or operational scaling behavior.
- A passing load smoke is not a production capacity claim.

Promotion of behavioral or continuity claims requires improved active-resume, correct-file/anchor, correction, and archaeology metrics against a baseline without safety regressions.
